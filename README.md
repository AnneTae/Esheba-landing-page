## Features

- Header with navigation, doctor search bar and statistics strip
- Consulting specialists cards
- "Why choose us" section with checklist
- Member testimonials with a review card
- "The Future of Quality Health" section
- Newsletter subscription form
- Footer with useful links, social icons and map
- Responsive layout for desktop, tablet and mobile

## Built with

- HTML5
- CSS3 (Flexbox, Grid, media queries)
- IBM Plex Sans font (Google Fonts)

## Project structure

```
Esheba-landing-page/
├── index.html
├── styles/
│   ├── base.css
│   ├── header.css
│   ├── main.css
│   └── footer.css
└── images/
```

## Run locally

1. Clone the repository:
```
   git clone https://github.com/AnneTae/Esheba-landing-page.git
```
2. Open the folder and double-click `index.html` in your browser.
